# Naufal Portfolio

Website portofolio pribadi dengan HTML, CSS, dan JavaScript murni.

## Cara menjalankan
1. Ekstrak folder `naufal-portfolio`.
2. Buka folder tersebut di Visual Studio Code.
3. Pasang ekstensi **Live Server** (opsional tetapi disarankan).
4. Klik kanan `index.html` → **Open with Live Server**.
   - Alternatif: buka `index.html` langsung melalui browser.

## Hal yang wajib disesuaikan sebelum dipublikasikan
- `assets/images/profile.jpg`: masukkan foto profil sendiri (disarankan rasio potret).
- `js/script.js`: ubah `CONTACT_EMAIL` menjadi email aktif.
- `index.html`: perbarui email, GitHub, LinkedIn, domisili, kampus, program studi, riwayat pendidikan, kemampuan, dan proyek.
- Tombol unduh CV tidak disertakan sesuai permintaan.
- Kartu proyek yang ada adalah contoh awal; ganti dengan proyek yang benar-benar pernah dibuat dan tambahkan tautan demo/repository.

## Fitur
- Responsive untuk desktop, tablet, dan ponsel.
- Dark mode / light mode, pilihan tema disimpan di browser.
- Animasi teks berganti.
- Reveal animation saat scroll.
- Filter proyek.
- Navigasi mobile dan menu aktif.
- Tombol kembali ke atas.
- Form kontak melalui aplikasi email (tidak membutuhkan backend).

## Catatan
Font Google Fonts dan ikon Font Awesome menggunakan CDN, sehingga memerlukan koneksi internet. Form kontak menggunakan `mailto:`; untuk formulir yang mengirim pesan langsung tanpa membuka aplikasi email, perlu layanan backend atau form service.
